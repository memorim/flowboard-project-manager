# Совместимость API и обновление базы

## API
`pnpm test:contract` сравнивает формы HTTP-ответов с [контрактом](API_CONTRACT.json). В выборку входят чтение, успешное создание и ошибка ввода. Удаление поля или изменение его типа ломает проверку; добавление поля допускается. Это набор ключевых сценариев, не исчерпывающая спецификация каждого endpoint.

Снимки не перезаписываются в CI. При согласованном изменении запустить проверку с `--record`, изучить diff и зафиксировать новый контракт вместе с изменением API.

## Обновление базы
`pnpm test:upgrade` извлекает предыдущий релиз по полному commit SHA из `tests/upgrade-baseline.json`, создаёт отдельную базу старым кодом, затем открывает её текущей версией. Проверяются сохранность записей, `integrity_check` и внешние ключи. Рабочая база не изменяется. Для получения отсутствующего commit нужен доступ к GitHub.

Перед обновлением рабочей установки всё равно создаётся отдельная резервная копия. Проверка выполняется на SQLite; она не подтверждает миграцию данных PostgreSQL или D1.

## GitHub Actions
Внешние Actions закреплены полными commit SHA, комментарии сохраняют имя версии. Dependabot предлагает обновление; перед слиянием выполняется CI.
