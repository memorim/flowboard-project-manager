# Проверка 24 октября 2026

- Node 24, pnpm 11: API/браузерное хранилище/резервная копия — 10 тестов.
- 6 E2E: основной путь, три участника и клавиатура; desktop/mobile.
- Reflow: 320 и 640 CSS px, диалог без горизонтального переполнения, Enter/Tab/Escape, видимый фокус и возврат к кнопке открытия.
- 640 CSS px проверяет узкую компоновку, соответствующую 1280 px при увеличении 200%; настоящий масштаб браузера и экранный диктор отдельно не проверялись.
- Типы и сборка проверены. CI выполняет тесты и сборку на Ubuntu 24.04, устанавливает только headless Chromium; повторный запуск отменяет предыдущий для той же ветки. Изменение одного Markdown/лицензии не запускает тяжёлые проверки.
- `pnpm measure`: 200 локальных HTTP-запросов, 10 параллельных клиентов; исходные цифры и условия — в SYNTHETIC_METRICS.json.
- Backup test использует только временную SQLite, сверяет таблицы и integrity/foreign_key_check. Это не настройка автоматических копий сервера.

Этот раунд — искусственное тестирование. Интервью с людьми, реальные отзывы и production-нагрузка не проводились. Скриншоты основного сценария и видео иллюстрируют демо, не метрики использования.
