# Проверка опубликованных интеграций — 07.11.2026

Проверена серверная версия на Render после успешного CI и обновления зависимостей.
Заголовок X-App-Revision совпал с запущенным коммитом после исправления его источника.

- Вход через GitHub прошёл до авторизованного интерфейса; личное пространство
  показало роль владельца и ранее сохранённую задачу из PostgreSQL.
- В разделе плана явно включён тестовый режим ЮKassa. Checkout завершился в
  тестовом магазине, возврат открыл приложение, а план стал активным.
- Независимая проверка роли владельца в PostgreSQL подтвердила succeeded,
  признак тестового платежа, фиксацию применения и действующий срок плана.
- Идентификаторы транзакции, аккаунта и снимки оплаты не публикуются в этом
  открытом репозитории. Реальные списания не выполнялись.

Осталось: исходящая почта. На опубликованном сервере регистрация по почте и
восстановление пароля выключены из-за отсутствия рабочего транспорта писем.
Вход через GitHub и приглашения по ссылке проверяются отдельно и не подтверждают
SMTP-доставку. Для завершения почтового этапа нужен реальный отправитель и
проверка доставки письма выбранному владельцем получателю.
