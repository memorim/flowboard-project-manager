# Размещённая демонстрация Flowboard

[Открыть](https://memorim-flowboard-live.amusedcorgi34.chatgpt.site). Native Sites / Vinext / Cloudflare Workers / D1. Это общая демонстрационная база, а не приватное пространство команды. Для изменения нужен вход через ChatGPT; чтение публичное. Реальные имена/email не записываются, используется псевдоним.

Здесь опубликованы поддерживаемые части серверного варианта: api-route.ts, схема, SQL-миграции и интеграционная проверка. Это выдержка из Sites-проекта, а не отдельный deploy-пакет: app/portfolio/ содержит копию основного React src, identity-helper подключается из штатного Vinext starter. Для локального запуска обычной версии используйте README в корне, а не эту папку.

Исходное расположение API: app/api/[...path]/route.ts; схемы: db/schema.ts; клиент: app/portfolio. Привязка D1 называется DB. Native Sites применяет миграции, выполняет вход и передаёт проверенную идентичность. Собственные JWT/OAuth-заглушки не используются. Миграции schema-only; примерные данные создаются идемпотентным INSERT OR IGNORE при первом обращении.

hosted-api.test.mjs запускается Node 24 против loopback preview (по умолчанию 5178). Локальный штатный mock-auth допускается только для этого теста; в размещённой версии __sites_local_auth не авторизует пользователя. Тест проверяет базу, запись/чтение, активность, отказы анониму, подмену заголовков и неверные данные. Два реальных внешних ChatGPT-пользователя в нём не моделируются.

Ограничения: все вошедшие могут редактировать задачи. Нет приватных команд, версионирования, realtime, гарантии uptime или резервного восстановления. Лимит 30 изменений в минуту — мягкий счётчик событий, не строгая квота при параллельных запросах. Используйте вымышленные данные. Подключение платных сервисов не выполнялось.
