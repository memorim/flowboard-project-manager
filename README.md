# Flowboard — управление проектами и задачами

Объединяет обзор проектов и kanban-доску команды.

**Тип:** Самостоятельный портфолио-проект. Проект использовался реальными пользователями. В репозитории показана демонстрационная версия; масштаб и коммерческие показатели не заявляются.

![CI](https://github.com/memorim/flowboard-project-manager/actions/workflows/ci.yml/badge.svg)

[Открыть интерактивное демо](https://memorim.github.io/flowboard-project-manager/)

Демо GitHub Pages использует localStorage, не обращается к Express API и не синхронизирует данные между посетителями. Серверная версия запускается командами ниже.

## Что работает
- Обзор проектов, счётчики задач и демонстрационная лента активности.
- Создание, поиск, смена статуса и удаление задач через REST API.
- Отдельное браузерное демо для проверки сценария без установки.

## Стек
React, TypeScript, Vite, Express, SQLite, Zod.

## Запуск и проверка
Node.js 24 и pnpm 11.

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm typecheck
pnpm build
pnpm start
```

## Технические решения
- Ссылки на проекты и исполнителей проверяются до записи в БД.
- Клиентская работа с API отделена от интерфейса; демо выбирается явно при сборке.

## Границы готовности
- Нет авторизации, ролей, realtime-синхронизации и совместного редактирования.
- Лента активности и проценты проектов — подготовленные данные, а не аналитика реальной команды.
- Разделы команды, календаря, настроек и часть кнопок показаны как макет.
- В GitHub Pages данные остаются в браузере посетителя и не передаются общей команде.
