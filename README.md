# Flowboard — управление проектами и задачами

Рабочее пространство для продуктовых команд: обзор проектов, kanban-доска, поиск, создание задач и обновление статусов.

## Возможности

- dashboard с показателями, прогрессом проектов и лентой активности;
- kanban-доска с поиском и быстрым переводом задач между статусами;
- создание и удаление задач;
- REST API с валидацией входных данных;
- SQLite без внешнего сервера базы данных;
- адаптивный интерфейс и API-тесты.

## Стек

React 19, TypeScript, Vite, Express 5, Zod, Node SQLite, Vitest, Supertest.

## Запуск

Требуется Node.js 22.5+ (используется встроенный модуль `node:sqlite`).

```bash
pnpm install
pnpm dev
```

Web-интерфейс откроется на `http://localhost:5173`, API — на `http://localhost:4100`.

На Windows можно запустить `start-local.cmd`: скрипт установит зависимости, соберёт проект и откроет готовое приложение на `http://localhost:4100`.

Production-режим вручную:

```bash
pnpm build
pnpm start
```

## Проверки

```bash
pnpm typecheck
pnpm test
pnpm build
```

Демо-данные создаются автоматически при первом старте в `data/flowboard.db`.
