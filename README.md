# Flowboard — проекты и задачи команды

Kanban-доска с редактированием задач, фильтрами, календарём и журналом фактических действий.

**Статус:** Самостоятельный портфолио-проект. Проект использовался реальными пользователями. Публикуется демонстрационная версия, без заявлений о масштабе или коммерческих показателях.

## Что работает
- Создание, редактирование и удаление задач, статусы и исполнители.
- Перенос карточек мышью или доступным select; фильтры по проекту, участнику, статусу и тексту.
- Команда, календарь сроков, реальные счётчики и процент готовности проекта.
- Активность при изменениях и сохранение после перезагрузки.
- Общая серверная демонстрация с D1 и входом через ChatGPT.

## Запуск и проверка
Node.js 24.18.0, pnpm 11.7.0. Стек: React, TypeScript, Vite, Express, SQLite, Zod.

```bash
npm install --global pnpm@11.7.0
pnpm install --frozen-lockfile
pnpm test
pnpm typecheck
pnpm exec playwright install chromium firefox webkit
pnpm test:e2e
pnpm build
pnpm start
```

## Технические решения
- Общая Zod-схема для Node API, браузерной версии и размещённого API.
- Прогресс считается из количества завершённых задач; журнал создаётся при действиях, а не из подготовленных показателей.
- Браузерные задачи и активность сохраняются одним JSON, чтобы не рассинхронизировать две записи.
- В размещённой версии задача и событие записываются транзакционным D1 batch. Идентичность передаёт Sites, подмена X-Demo-Actor не используется.

## Границы готовности
- Размещённое демо — общее пространство: любой вошедший участник может менять демонстрационные задачи. Не вводите конфиденциальные данные.
- Отдельные пространства и роли работают в серверной версии. Корзина, восстановление и история полей реализованы. Нет realtime-подписок; обновление — после действия или по кнопке.
- Node-версия локально использует доверенный X-Demo-Actor и не является защищённым публичным API.
- В GitHub Pages участники и изменения существуют только в одном браузере.

## Командная работа и воспроизводимые проверки
- Отдельные рабочие пространства; владелец, редактор и наблюдатель.
- Одноразовые приглашения на 7 дней, изменение ролей, удаление участника, экспорт JSON владельцем.
- Версия задачи проверяется в SQL: устаревшее сохранение получает 409, черновик остаётся в форме.
- Искусственные участники проверены в изолированных контекстах браузера. Реальные люди в этом раунде не участвовали.

[Сценарии и ограничения проверки](docs/SYNTHETIC_TESTING.md) · [Измерения](docs/SYNTHETIC_METRICS.json) · [Подготовка к собеседованию](docs/INTERVIEW.md)

Повторить: `pnpm test`, `pnpm test:e2e`, `pnpm measure`. В `tests/backup.test.ts` проверяется восстановление копии временной базы, без изменения рабочей БД.

## Проверка документации и обновлений

`python .github/scripts/check_docs.py` проверяет ссылки на файлы и изображения в Markdown, регистр имён и случайные локальные ссылки. Примеры команд внутри блоков кода не проверяются как ссылки. `--external` дополнительно проверяет публичные HTTP-ссылки: 404/410 считаются ошибками; авторизация, сетевые сбои и ограничения сервиса отмечаются как непроверенные. HTTP-проверка запускается еженедельно и вручную; локальные ссылки — при каждом push/PR. Фрагменты внутри страниц не проверяются.

Dependabot еженедельно предлагает сгруппированные обновления зависимостей и GitHub Actions. Автоматического слияния нет; обновления проходят CI. [История версии](CHANGELOG.md).
